# Glossário de termos (PT-BR)

Tabela de referência para manter a tradução consistente com os manuais em inglês/português na pasta `docs`.

| Inglês | Tradução PT-BR | Observações |
| --- | --- | --- |
| Basin | Bacia | Usado para identificar a numeração das bacias no mapa. |
| Dam Base | Base de Barragem | Parte inferior da barragem. |
| Elevation | Elevação | Extensão construída sobre uma barragem existente. |
| Conduit | Conduto | Canal que leva a água da barragem até a usina. |
| Powerhouse | Usina | Estrutura que gera Energia. |
| Headstream | Nascente | Azulejos onde as Gotas d'Água entram no mapa. |
| Water Drop | Gota d'Água | Unidade de água que flui entre as bacias. |
| Energy Track | Trilha de Energia | Trilha de pontuação temporária por rodada. |
| Victory Points | Pontos de Vitória | Pontuação final. |
| Company Board | Tabuleiro de Companhia | Tabuleiro individual do jogador. |
| Construction Wheel | Roda de Construção | Roda onde o maquinário fica bloqueado durante construções. |
| Engineer | Engenheiro | Trabalhador usado para ações. |
| Machinery | Maquinário | Peças de Escavadoras e Betoneiras. |
| Excavator | Escavadora | Tipo de maquinário laranja. |
| Concrete Mixer | Betoneira | Tipo de maquinário cinza. |
| Private Building | Construção Privada | Edifício ligado a fichas próprias. |
| External Work | Obra Externa | Fichas de objetivos do tabuleiro de gestão. |
| Contract Office | Departamento de Contratos | Espaço de ação para contratos disponíveis. |
| Advanced Technology Tile | Ficha de Tecnologia Avançada | Usada para construir e aplicar bônus. |
| Bonus Tile | Ficha de Bônus | Bônus de pontuação por rodada. |
| Objective Tile | Ficha de Objetivo | Condições de pontuação final. |
| Water Management | Gestão de Água | Ação para adicionar Gotas d'Água nas Nascentes. |
| Player Order | Ordem de Turno | Sequência de jogadores na rodada. |
